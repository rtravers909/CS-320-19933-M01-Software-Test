# CS-320-19933-M01-Software-Test
Embedding security measures across all stages of the Software Development Life Cycle (SDLC) is essential for creating code that is both robust and safe. This integrated approach is often called the Secure SDLC (SSDLC). Security begins at the Requirements stage by establishing compliance mandates and security goals alongside functional needs. When the system is being Designed, teams must proactively use Threat Modeling to expose potential weaknesses and incorporate security controls, such as enforcing the principle of least privilege. In the Implementation phase, developers should follow secure coding practices (e.g., careful input validation) and leverage Static Analysis (SAST) tools to check their code. Finally, the Testing phase must rigorously include penetration testing and vulnerability assessments, while the Maintenance phase requires ongoing monitoring and prompt patching to manage emerging threats effectively.

Understanding and integrating what users require is the foundational step for developing useful software, a methodology known as User-Centered Design (UCD). This process kicks off with Elicitation and Discovery by conducting user research, such as interviews and surveys, to gain a deep comprehension of the user's objectives, workflows, and difficulties. Next is Analysis and Specification, where these broad needs are converted into detailed, measurable requirements, frequently captured in the format of User Stories or use cases. The procedure concludes with Validation, which involves testing early prototypes and using User Acceptance Testing (UAT) on the finished product to confirm it successfully addresses the end-user's genuine needs.
